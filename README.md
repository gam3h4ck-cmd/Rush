# Rush

Planning turni per bar e ristoranti. Web app statica (cartella `app/`) su Cloudflare Pages, dati su Supabase.

- `app/` → l'app pubblicata (index.html = admin, staff.html = link dipendenti)
- `supabase/schema.sql` → schema del database
- `.github/workflows/deploy.yml` → pubblicazione automatica a ogni push su `main`

Guida completa: `GUIDA.md`.
