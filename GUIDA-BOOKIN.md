# Book-in · prenotazioni

Gira sullo stesso sito e sullo stesso Supabase di Rush.

- Gestione (staff/titolare): https://rushv2.pages.dev/bookin/
- Pagina pubblica: https://rushv2.pages.dev/bookin/prenota.html#<indirizzo-del-locale>

## Installazione (una volta)
1. Supabase → SQL Editor → incolla `supabase/bookin.sql` → Run.
2. GitHub Desktop → Commit → Push.

## Primo locale
1. Apri /bookin/ → "Crea un account" (o accedi).
2. Scegli nome e indirizzo della pagina (es. `da-gino`).
3. Impostazioni: tavoli sulla piantina, turni, durate, limite arrivi ogni 15 min.
4. Copia il link della pagina di prenotazione e mettilo su Instagram / Google / sito.
